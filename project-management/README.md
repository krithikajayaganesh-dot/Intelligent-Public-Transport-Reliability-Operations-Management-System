\# Project Management



\## Methodology



The project follows Agile Scrum practices.



\## Project Epics



The project is organized into five major Epics:



1\. Real-Time Transport Tracking

2\. Reliability \& Delay Prediction

3\. Passenger Experience \& Smart Routing

4\. Fleet Operations \& Incident Management

5\. Admin \& Transport Analytics



\## User Story Labels

\- frontend

\## Product Backlog



The Product Backlog organizes the system requirements and user stories according to functional priorities and dependencies.



\## Sprint Planning



Sprint planning is used to prioritize critical functionality and progressively develop advanced features.



Important capabilities include:



\- Real-time vehicle tracking

\- Arrival-time prediction

\- Delay prediction

\- Passenger notifications

\- Overcrowding prediction

\- Smart routing

\- Fleet operations

\- Transport analytics



\## Challenges



Some challenges identified during project planning include:



\- Establishing dependencies between vehicle tracking and arrival-time prediction

\- Availability of real-time transport data

\- Integration between passenger-facing and authority-facing modules

\- Data requirements for overcrowding prediction

\- Managing route disruptions across multiple modules



\## Areas for Improvement



\- Define data sources and data availability requirements early

\- Finalize dependencies between tracking and prediction modules

\- Assign subtasks at the beginning of each sprint

\- Establish reliability metrics for predictions

\- Improve prioritization of AI and predictive features

\- Define notification workflows before implementation



\## Tools



The project uses Jira for Agile project management and GitHub for version control and collaboration.
